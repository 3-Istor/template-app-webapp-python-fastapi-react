## Claude Code

- The `cnp` plugin (MCP connection and platform guides) is declared in
  `.claude/settings.json`. Accept it when Claude Code offers it after you trust
  the folder, or run `/plugin install cnp@cnp-agent-kit`. Its skills
  `cnp-release` and `cnp-troubleshoot` handle releases and incidents.
- Personal instructions go in `CLAUDE.local.md`, which is git-ignored.
